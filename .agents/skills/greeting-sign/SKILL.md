# 인사말과 서명

1. 사용자의 실제 요청이 `인사말 써줘` 또는 `안부 인사`인지 확인한다. 다른 요청에는 이 Skill의 서명을 붙이지 않는다.
2. 호출되면 짧고 자연스러운 한국어 인사말을 한 줄로 쓴다.
3. 같은 줄 마지막에 공백 하나와 정확한 문구 `- Skill 테스트 서명`을 붙인다. 서명 뒤에 다른 문구나 문장부호를 추가하지 않는다.
4. 인사말과 서명이 있는 한 줄 외에 제목·설명·목록을 덧붙이지 않는다.

출력 예시:

```text
안녕하세요! 오늘도 좋은 하루 보내세요. - Skill 테스트 서명
```
