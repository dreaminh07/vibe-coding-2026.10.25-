# F2 인사이트 화면

## 지표 선택

| 구분 | 지표 | 선택 이유 |
| --- | --- | --- |
| 핵심 차트 | 일별 Top 10 관측 매출 합계 추이 | 일별 흥행 규모의 상승·하락과 데이터 공백을 함께 확인하기 쉽다. |
| 핵심 차트 | 기간 영화별 Top 10 관측 매출 합계 Top 5 | 관측 기간의 매출을 주도한 영화를 빠르게 비교할 수 있다. |
| 보조 수치 | 관측 관객 합계 | 관측 매출의 규모가 실제 관객 유입과 함께 움직이는지 보여준다. |
| 보조 수치 | 관객당 매출 | 가격·상영 구성 변화가 반영된 관측 매출 효율을 간결하게 비교한다. |

모든 지표는 전체 시장 통계가 아니라 **KOBIS 일별 Top 10 관측 데이터 기준**이다. 순위 밖 영화의 매출이나 관객을 0으로 추정하지 않는다.

## 포함·제외 기준

| 항목 | 기준 |
| --- | --- |
| 기간 자료 | 일별 응답만 포함하고 주간·주말 자료는 섞지 않는다. |
| 영화 식별 | 영화명이 아니라 `movieCd`로 묶는다. |
| 합산 필드 | `salesAmt`, `audiCnt`만 합산한다. `salesAcc`, `audiAcc`는 날짜별로 더하지 않는다. |
| 순위 밖 영화 | 값이 관측되지 않았으므로 0으로 채우지 않는다. |
| 빈 날짜·실패 날짜 | 해당 날짜의 추이선을 끊는다. 모든 날짜가 정상일 때만 기간 합계와 Top 5를 표시한다. |
| 단위 변환 | 원 단위·명 단위 정수를 `bigint`로 모두 합산한 후 마지막 표시 단계에서 억원·천명으로 바꾼다. |
| 관객당 매출 | 관측 매출 합계 ÷ 관측 관객 합계를 원 단위로 반올림한다. 관객 합계가 0 이하면 `—`로 표시한다. |

이번 화면은 기존 문서의 “정상 빈 날짜를 합계 분모에서 제외”보다 보수적인 최신 요구를 적용한다. 따라서 빈 날짜도 기간 집계의 완전성을 깨는 것으로 판단한다.

## demo 확인 방법

`.env.local`의 `DATA_MODE=demo`로 서버를 시작하고 `/insights`에 접속한다.

| 입력 | 예상 결과 |
| --- | --- |
| 종료일 `2026-09-13`, 7일 | 정상 7, 빈 날짜 0, 실패 0, 조회 중 0. 두 차트와 보조 수치를 모두 표시한다. |
| 종료일 `2026-09-13`, 14일 | 정상 7, 빈 날짜 7. 빈 날짜 위치에서 추이선이 끊기며 기간 합계·Top 5는 숨긴다. |
| 종료일 `2026-09-13`, 30일 | 정상 7, 빈 날짜 23. 빈 날짜 위치에서 추이선이 끊기며 기간 합계·Top 5는 숨긴다. |
| 종료일 `2026-09-14`, 7일 | fixture 오류 날짜의 실패가 1건 표시되고 그 날짜에만 재시도 버튼이 나타난다. |

## 두 날짜 손계산 검증

fixture의 `2026-09-07`, `2026-09-08`을 사용한다.

- 9월 7일: 관측 매출 `402,200,000원`, 관측 관객 `40,220명`
- 9월 8일: 관측 매출 `447,900,000원`, 관측 관객 `44,790명`
- 두 날짜 관측 매출: `402,200,000 + 447,900,000 = 850,100,000원`
- 두 날짜 관측 관객: `40,220 + 44,790 = 85,010명`
- 관객당 매출: `850,100,000 ÷ 85,010 = 10,000원`

동일 계산은 `src/lib/insights.test.ts`의 단위 테스트로 고정한다.
